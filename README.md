# Healthcare Patient Data Analysis (Beginner)

## Overview
This repository focuses on exploratory data analysis (EDA) and operational insights using clinical and hospital management datasets. The goal is to identify trends in patient care, admission rates, and operational efficiency.

## Core Analytics Focus
* **Patient Demographics**: Analyzing patient distribution by age, gender, and primary medical conditions.
* **Length of Stay (LOS) Analysis**: Tracking the average number of days patients spend in the hospital to help optimize bed availability.
* **Admission Trends**: Visualizing peak admission times (seasonal or weekly) to assist with hospital staffing demand forecasting.

## Tech Stack
* **Python (Pandas & Seaborn)**: For data cleaning, data normalization, and creating heatmaps.
* **SQL**: For querying patient billing and administrative records.
